Project 2: AIML-02 – AI-Assisted Medical Imaging and Diagnosis System

Repository: [https://github.com/duaashaheen9/AIML-02-Medical-Imaging]

Specialization: Machine Learning

An AI-assisted chest X-ray review prototype using DenseNet121 to score 14 findings, Grad-CAM for visual explanations, and a clinician review workflow.

Key Results:

    Dataset: NIH ChestX-ray14.

    Test set: 25,596 images with patient-level separation.

    Macro AUROC: 0.802.

    Macro AUPRC: 0.268.
